# 1. Project Overview

## Project Purpose

MotionFit is a browser-based fitness web application that combines real-time motion tracking with gamified exercise experiences. Using MediaPipe pose detection technology, users interact with fitness mini-games through physical body movements captured via webcam.

The project aims to make exercise more engaging and motivating by integrating gameplay mechanics such as experience points (XP), levels, and streak systems into workout activities.

In addition to delivering a functional MVP, the project provides the development team with practical experience in fullstack development, computer vision integration, real-time interaction systems, and collaborative software engineering practices.

---

# 2. Project Objectives

## SMART Objectives

### 🎯 Objective 1 — Interactive Fitness Experience
Develop a fully functional browser-based fitness application that allows users to control mini-games using body movements detected through webcam motion tracking by the end of the MVP development phase.

### 📈 Objective 2 — Improve User Engagement
Implement gamification features including XP progression, achievement tracking, and daily streak systems to encourage exercise consistency and improve long-term user motivation.

### ⚡ Objective 3 — Real-Time Motion Tracking Integration
Successfully integrate MediaPipe pose detection into the application to provide responsive real-time movement analysis and gameplay interaction with minimal latency.

# 4. Project Scope

## ✅ In Scope

- Browser-based fitness web application
- Webcam-based body movement tracking
- MediaPipe pose detection integration
- One functional fitness mini-game
- Real-time motion-controlled gameplay
- User XP and progression system

## ❌ Out of Scope

- Native iOS or Android applications
- Smartwatch or wearable device integration
- Third-party fitness app integrations
- Voice coaching or audio-guided workouts

# 5. Risk Assessment

| Risk | Impact | Likelihood | Mitigation Strategy |
|---|---|---|---|
| Pose estimation inaccuracies | High | Medium | Extensive testing across exercises and environments |
| Occlusion or body visibility issues | Medium | Medium | Provide user positioning guidelines and calibration checks |
| Poor lighting conditions | Medium | High | Include camera setup validation and lighting recommendations |
| Low-performance devices | Medium | Medium | Optimize rendering and detection frequency |
| MediaPipe API updates or compatibility issues | Medium | Low | Maintain version control and stable dependency management |
| Legal liability from incorrect exercise feedback | High | Low | Include disclaimers and clear Terms of Service |
| Privacy concerns regarding webcam usage | High | Medium | Avoid storing video data and implement transparent privacy policies |
